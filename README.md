## This alternative store allows you to install misc apps.

### Add it to your Umbrel

1. Open the App Store, click the button with three dots next to the search
   box, then **Community App Stores**. On umbrelOS 2.0, once you have added a
   community store, that menu has **Manage** under it: choose that.
2. Paste `https://github.com/Horizon-btc/Bitcoin-store` and click **Add**.
3. Click **Open** next to Misc. The search box on the main App Store page does
   not search community stores, so find the apps on the Misc page.

If you added this store before as `https://github.com/Retropex/Bitcoin-store`
(with or without `.git`), you already have it: that is the same store. Do not
add it a second time. On umbrelOS 2.0 a store added under both addresses blocks
installs and updates of its apps, and Install shows "This app ID conflicts with
another app store." Remove one of the two entries under Community App Stores,
then Manage, to fix it.
